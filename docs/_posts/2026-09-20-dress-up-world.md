Daughter created a game (*bit* of help from Claude) called [Dress Up World](https://tobyandzuzka.com/dress-up-world/), which is freely available.
It's a, now strap in here, have an avatar you can dress up, and then move around some rooms which you can decorate, explore, find and perform certain
actions like cooking and eating (will add more over time). It's simple, cartoonish, SVG, works in the browser so PC, phone, iPad etc.
